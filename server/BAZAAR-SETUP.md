## ۲. دسترسی API برای تأیید خرید (سمت سرور)
1. در پنل توسعه‌دهنده‌ی بازار به بخش API (دسترسی API پرداخت) برو و یک **client** بساز. آدرس بازگشت (redirect URI) را آدرس Worker بگذار، مثلاً `https://hooshyar.hurehsamadi.workers.dev/`.
2. `client_id` و `client_secret` را در Cloudflare (Secret) بگذار: `BAZAAR_CLIENT_ID` و `BAZAAR_CLIENT_SECRET`.
3. این آدرس را در مرورگر باز کن (به‌جای CLIENT_ID مقدار واقعی را بگذار) و دسترسی را تأیید کن:
   `https://pardakht.cafebazaar.ir/devapi/v2/auth/authorize/?response_type=code&access_type=offline&redirect_uri=https://hooshyar.hurehsamadi.workers.dev/&client_id=CLIENT_ID`
4. بعد از تأیید به آدرس Worker برمی‌گردی؛ در نوار آدرس مرورگر مقدار `code=...` هست. آن را کپی کن.
5. پنل مدیریت ← کارت «پرداخت کافه‌بازار» ← کد را بچسبان ← «تبدیل به refresh token». مقدار نمایش‌داده‌شده را در Cloudflare به‌عنوان Secret با نام `BAZAAR_REFRESH_TOKEN` بگذار.
6. دکمه‌ی «تست اتصال به API بازار» را بزن؛ باید ✅ ببینی.
(اگر نام بسته‌ی اپ در بازار فرق دارد، متغیر `BAZAAR_PACKAGE` را هم بگذار.)

## ۳. انتشار
- APK امضاشده (release) را در پنل بازار آپلود کن. فقط وقتی برنامه از **خود بازار** نصب شود، دکمه‌ی خرید به پرداخت بازار وصل می‌شود؛ نسخه‌ی مستقیم مثل قبل با کد و تلگرام کار می‌کند.
- برای تست قبل از انتشار، از حالت «تست» پنل بازار و گوشی دارای کافه‌بازار استفاده کن.

## نحوه‌ی کار
خرید ← بازار ← اپ توکن خرید را به Worker می‌فرستد ← Worker با API بازار راستی‌آزمایی می‌کند (هر توکن فقط یک بار پذیرفته می‌شود) ← اشتراک روی حساب اعمال و فروش در آمار ثبت می‌شود (و در تلگرام خبر می‌آید) ← اپ خرید را «مصرف» می‌کند.
اگر بعد از پرداخت اینترنت قطع شد، دکمه‌ی «بازیابی خرید» (یا باز کردن صفحه‌ی قیمت‌ها) خرید را دوباره ثبت می‌کند.

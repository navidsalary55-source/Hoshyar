# راه‌اندازی سرور هوشیار (Cloudflare Worker + D1)

این سرور سه کار می‌کند: کلیدها را پنهان نگه می‌دارد، به هر کاربر سهمیه‌ی رایگان روزانه می‌دهد و با «کد اشتراک» سهمیه‌ی بیشتر و صدای واقعی و آواز حرفه‌ای باز می‌کند.
همه‌اش روی پلن رایگان Cloudflare اجرا می‌شود (محدودیت‌ها را در سایت Cloudflare چک کن).

## ۱. ساخت پایگاه داده
Cloudflare Dashboard ← Storage & Databases ← D1 ← Create ← نام: `hooshyar`. (جدول‌ها را خود Worker می‌سازد.)

## ۲. ساخت Worker
Workers & Pages ← Create ← Hello World ← Deploy ← Edit code ← محتوای `worker.js` را جایگزین کن ← Deploy.

## ۳. اتصال دیتابیس
Worker ← Settings ← Bindings ← Add ← D1 database ← Variable name: **`DB`** ← دیتابیس `hooshyar`.

## ۴. کلیدها (Settings ← Variables and Secrets ← نوع Secret)
| نام | توضیح |
|---|---|
| `ADMIN_TOKEN` | یک رمز طولانی برای پنل مدیریت (الزامی) |
| `GROQ_KEY` | کلید Groq؛ می‌توانی چند کلید را با کاما بگذاری تا سهمیه چند برابر شود (الزامی) |
| `CEREBRAS_KEY` `MISTRAL_KEY` `GEMINI_KEY` `OPENROUTER_KEY` | اختیاری؛ ترتیب: Groq ← Cerebras ← Mistral ← Gemini ← OpenRouter. هر کدام سهمیه‌اش پر شد، خودکار بعدی استفاده می‌شود. از هر سرویس می‌توانی چند کلید (از چند حساب) با کاما بگذاری |
| `POLL_KEY` | اختیاری؛ کلید Pollinations برای ساخت تصویر پایدارتر (تصاویر همه از Worker می‌گذرند) |
| `ELEVEN_KEY` | اختیاری؛ برای صدای واقعی اشتراک‌داران و آواز حرفه‌ای |

## ۵. تنظیم سهمیه (اختیاری، نوع Text)
همه‌ی بخش‌ها برای همه باز است و طرح رایگان سهمیه‌ی روزانه‌ی کم دارد (`FREE_CHAT`=30 • `FREE_STT`=10 • `FREE_TTS`=15 • `FREE_IMAGE`=6)؛ آواز حرفه‌ای فقط با اشتراک است. ذخیره، دانلود و کپی نتیجه در اپ فقط با اشتراک ممکن است. اعداد اشتراک: `PAID_CHAT`=500 • `PAID_STT`=150 • `PAID_TTS`=300 • `PAID_ELEVEN_CHARS`=60000 (حرف در ماه) • `PAID_IMAGE`=60 (تصویر در روز) • `PAID_MUSIC`=3 (آهنگ در ماه) • `PAID_AVATAR`=20 (کارتونی‌سازی با هوش مصنوعی در ماه) • `IP_DAILY`=400.
`ELEVEN_FA`=1 را فقط وقتی بگذار که مطمئنی ElevenLabs فارسی را خوب می‌خواند؛ تا آن موقع فارسی با صدای رایگان مایکروسافت خوانده می‌شود.

## ۶. استفاده
- آدرس Worker (مثلاً `https://xxx.workers.dev`) را در برنامه، «تنظیمات ← حساب و اشتراک» بگذار. برای نسخه‌ی عمومی در `Config.SERVER_URL` (فایل Store.kt) بنویس تا کاربران چیزی وارد نکنند.
- پنل مدیریت فقط روی Worker است و در اپ نیست: `آدرس‌ورکر/admin` (برای امنیت بیشتر متغیر `ADMIN_PATH` را مثلاً `panel-x7k29q` بگذار تا آدرس پنل حدس‌زدنی نباشد) را در مرورگر گوشی باز کن (می‌توانی بوکمارکش کنی) ← رمز `ADMIN_TOKEN` ← مدت (۱ تا ۱۲ ماه) و تعداد ← «بساز». کد را کپی کن و به کاربر بده؛ او در برنامه «تنظیمات ← حساب و اشتراک» وارد می‌کند. فهرست کدها (آزاد/استفاده‌شده) هم همان‌جاست.
- «آمار» تعداد دستگاه‌های امروز و اشتراک‌های فعال را نشان می‌دهد.

## نکته‌ها
- سهمیه‌ی رایگان Groq برای کل حساب است، نه هر کاربر. با کاربر زیاد، چند کلید (کاما) و کلید سرویس‌های دیگر بگذار یا اشتراک را تشویق کن.
- پرداخت بازار/مایکت بعداً به همین `redeem` وصل می‌شود: سرور رسید را تأیید و اشتراک را فعال می‌کند.
- Edge TTS غیررسمی است و ممکن است مایکروسافت آن را ببندد؛ برای محصول جدی بعداً یک موتور صدای رسمی اضافه کن.


## کارتونی‌سازی عکس با هوش مصنوعی (فقط اشتراک‌داران)
مسیر `/v1/avatar`. یکی از این دو را تنظیم کن:
1. **پیشنهادی، شباهت چهره عالی:** Secret با نام `OPENAI_KEY` (کلید OpenAI؛ مدل `gpt-image-1`؛ هزینه‌ی هر تصویر حدود چند سنت). اختیاری: `AVATAR_QUALITY` = low / medium / high و `AVATAR_MODEL`.
2. **ارزان‌تر، شباهت کمتر:** در Worker → Settings → Bindings یک «Workers AI» با نام `AI` اضافه کن (بدون کلید جدا).
سهمیه با `PAID_AVATAR` (پیش‌فرض ۲۰ در ماه برای هر اشتراک‌دار) تنظیم می‌شود؛ کاربر رایگان دسترسی ندارد.

نکته: اگر `OPENAI_KEY` نباشد ولی `GEMINI_KEY` (همان کلید چت) باشد، کارتونی‌سازی با `gemini-2.5-flash-image` انجام می‌شود (در صورت رایگان بودن سهمیه‌ی گوگل برای این مدل). اولویت: OpenAI ← Gemini ← Workers AI.

صدای فارسی: اگر `GEMINI_KEY` باشد، فارسی اول با Gemini TTS (طبیعی‌تر) ساخته می‌شود و اگر سهمیه/خطا بود خودکار با صدای Edge (دیلارا/فرید) ادامه می‌دهد. خاموش‌کردن: `GEMINI_TTS`=0. صداها: `GEMINI_VOICE_F` (پیش‌فرض Kore) و `GEMINI_VOICE_M` (Charon).

## بهبود کیفیت عکس با هوش مصنوعی (فقط اشتراک‌داران)
مسیر `/v1/enhance`، سهمیه‌ی ماهانه‌ی `PAID_ENHANCE` (پیش‌فرض ۴۰). یکی را تنظیم کن:
1. **پیشنهادی:** Secret با نام `REPLICATE_TOKEN` (از replicate.com). مدل Real-ESRGAN با بزرگ‌نمایی ۲ برابر و بهبود چهره؛ بسیار ارزان (کسری از سنت برای هر عکس). مدل با `ESRGAN_MODEL` قابل تغییر است.
2. در نبود آن، `GEMINI_KEY` یا `OPENAI_KEY` (همان کلیدهای قبلی) با دستور بازسازی عکس استفاده می‌شوند.


## پنل مدیریت (نسخه‌ی فروش)
- پلن‌ها همان لیست قیمت اپ هستند؛ با انتخاب پلن، مبلغ خودش پر می‌شود (قابل تغییر است).
- هنگام ساخت کد می‌توانی نام خریدار را یادداشت کنی. دکمه‌ی «پیام آماده» متن کامل همراه کد و روش فعال‌سازی را کپی می‌کند تا برای مشتری بفرستی.
- در «ورود و نمایش آمار»: فروش ۳۰ روز اخیر، کل فروش، و فهرست اشتراک‌هایی که تا ۷ روز دیگر تمام می‌شوند (برای یادآوری تمدید) را می‌بینی.
- کدهای آزاد را می‌توان «لغو» کرد. «فعال‌سازی دستی» هم اگر مبلغ بزنی، به‌عنوان فروش ثبت می‌شود.
- ستون‌های جدید خودکار به پایگاه داده اضافه می‌شوند؛ نیازی به کار دستی نیست.

## دعوت دوستان
- هر گوشی یک کد ۶ حرفی دارد. دوست با وارد کردن آن، `REF_INVITEE_DAYS` روز (پیش‌فرض ۳) اشتراک می‌گیرد.
- وقتی دوست حداقل ۵ درخواست از اپ زد، دعوت‌کننده `REF_INVITER_DAYS` روز (پیش‌فرض ۷) می‌گیرد؛ حداکثر `REF_MAX` دعوت (پیش‌فرض ۱۰).
- هر IP روزی حداکثر ۳ بار می‌تواند کد دعوت وارد کند. هر گوشی فقط یک کد می‌تواند ثبت کند و کد خودش را نمی‌تواند.
- متغیرهای بالا اختیاری‌اند؛ آمار دعوت‌ها در پنل مدیریت (بخش آمار) هست.

## حساب ایمیلی و پنل کاربران
- ثبت‌نام فقط هنگام خرید یا بازیابی اشتراک خواسته می‌شود. ورود با کد ۶ رقمی ایمیلی است (۱۰ دقیقه اعتبار، ۵ تلاش).
- متغیرهای لازم برای ارسال ایمیل (Brevo): `BREVO_KEY` (کلید API)، `MAIL_FROM` (ایمیل فرستنده‌ی تأییدشده در Brevo)، و اختیاری `MAIL_NAME`.
- اختیاری، اعلان ثبت‌نام جدید در تلگرام: `TG_BOT_TOKEN` و `TG_CHAT_ID`.
- اشتراک روی حساب ایمیلی می‌نشیند و روی همه‌ی گوشی‌های واردشده با آن ایمیل اعمال می‌شود. اشتراک قبلی گوشی هنگام ورود به حساب منتقل می‌شود.
- پنل مدیریت ← کارت «کاربران»: جستجو با ایمیل یا شناسه‌ی گوشی، دیدن زمان ثبت‌نام و آخرین ورود، وضعیت اشتراک، مصرف کل و امروز به‌تفکیک بخش، کدهای فعال‌شده، وضعیت دعوت‌ها، افزودن روز اشتراک (با ثبت مبلغ)، لغو اشتراک و مسدود/آزادکردن کاربر.
- آمار بالای پنل: کل گوشی‌ها، جدید ۲۴ ساعت و ۷ روز، فعال ۷ روز، تعداد حساب‌های ایمیلی.

## ورود با تلگرام (پیشنهادی برای کاربران ایرانی)
1. در تلگرام به `@BotFather` پیام بده ← `/newbot` ← نام و نام‌کاربری ربات (مثلاً `HooshyarLoginBot`) ← توکن را کپی کن.
2. در Cloudflare متغیر `TG_BOT_TOKEN` را با همان توکن بساز (بهتر است Secret باشد) و `worker.js` را Deploy کن.
3. پنل مدیریت ← کارت «ربات تلگرام» ← «فعال‌سازی / بازنشانی ربات». باید «✅ ربات @… فعال شد» ببینی (وبهوک خودکار تنظیم می‌شود).
4. (اختیاری) برای اعلان ثبت‌نام جدید، `TG_CHAT_ID` را هم بگذار: شناسه‌ی عددی چت خودت؛ از ربات `@userinfobot` می‌گیری.
- جریان کاربر: «ورود با تلگرام» در اپ ← ربات باز می‌شود ← Start ← ربات تأیید می‌کند ← اپ خودکار وارد می‌شود. بدون تایپ کد.
- حساب‌های تلگرامی در پنل با نام کاربری (@…) دیده و جستجو می‌شوند.
